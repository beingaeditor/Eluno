# Eluno 0.2.0 — internal beta

- Shared service and versioned media/session contracts for web, Windows and Android.
- Windows application starts its companion automatically; no manual localhost setup for users.
- Native Android QR pairing, nearby-service discovery, system file selection, Media3 video and photo viewer.
- Encrypted Android LAN transport with invitation-bound certificate pinning and explicit computer approval.
- Two-way on-demand media, range seeking, photo navigation and zoom, connection expiry, stop sharing and device removal.
- Shared-media search and explicit owner-controlled saving copies.
- Local diagnostics export, setup help, build helpers, CI definition and artifact checksums.

Known limitations: physical acceptance and real-user beta pending; Android foreground use only; private IPv4 LAN only; coordinator must stay open; codec-dependent playback; no HEIC conversion, iOS app, remote relay, synchronization, automatic updater or published distribution. Final browser verification was blocked by automatic approval review reporting an account usage limit.
